# NailLang versions

Browse source, language tours, cookbooks and execution instructions by selecting a version tag from the [Git tags](https://github.com/Spyryto/NailLang/tags) list. Each tag gives the **whole source tree** at that version; there are no version-numbered source directories.

- The original v0.1–v0.3 snapshots are standalone JavaScript/PHP prototypes (before the Haxe `src/` layout).
- `v0.16`, `v0.28`, and `v0.29` are experimental numeric labs and appear under `experiments/numeric/`, while `src/` continues to show the preceding main compiler. `v0.29-runtime` integrates the runtime changes into the compiler.
- `LANGUAGE-TOUR.md`, `COOKBOOK.md` and `RUNNING.md` track the main compiler. For numeric-lab tags, the corresponding guides are under `experiments/numeric/`.

The history is reconstructed from sources, not imported from the old private Git history. No license has been selected yet.

The current development head may be newer than the latest release tag. See [the root language tour](../LANGUAGE-TOUR.md) for the current development version; the table in [versions.md](./versions.md) lists released historical tags.
