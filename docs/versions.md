# NailLang historical versions

Use the Git tag for the source, language tour, cookbook, and run instructions appropriate to each release. The repository does not keep a separate source directory per historical version. In-progress changes in `main` are documented at the root; only tagged and published versions appear in the historical table.

Numeric research tags v0.16, v0.28 and v0.29 retain the previous compiler alongside experiments/numeric.
